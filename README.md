# 📊 Sales Data Analysis Project

## 📌 Overview

This project analyzes sales data to identify trends, top-performing regions, and product categories.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib

## 📂 Dataset

* Sales dataset (CSV format)

## 📊 Analysis Performed

* Total Sales Calculation
* Sales by Region
* Sales by Category
* Sales by Sub-Category
* Top 5 Products
* Yearly Sales Trend

## 📈 Visualizations

* Bar chart for Sales by Region
* Bar chart for Sales by Category
* Line chart for Sales Trend

## 🧠 Key Insights

* Some regions generate higher sales than others
* Certain categories dominate revenue
* Sales trends change over years
* Few products contribute most to total sales

## 🚀 How to Run

1. Install required libraries:
   pip install pandas numpy matplotlib

2. Run the script:
   python sales_analysis.py
